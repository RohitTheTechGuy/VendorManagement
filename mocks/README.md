# VendorManagement

## Vendor Onboarding — Wireframe Prototype

`vendor-onboarding-prototype.html` is a functional, self-contained HTML/CSS
prototype of the vendor onboarding journey (buyer, platform and vendor lanes).
It covers ~15 screens across four sections, including an interactive 12-step
"journey sequence viewer" — click the steps in the left sidebar to preview each
desktop/mobile screen.

> **Note:** Opening the file's page on GitHub only shows the HTML *source code*,
> not the rendered wireframe. Use one of the options below to preview it.

### How to preview the wireframe in a browser

#### Option A — Live link (recommended, nothing to install)

The prototype is published with GitHub Pages. Just open:

- **https://mjha1.github.io/VendorManagement/** (redirects to the prototype), or
- **https://mjha1.github.io/VendorManagement/vendor-onboarding-prototype.html**

GitHub Pages serves the site directly from the `main` branch, so it updates
automatically a minute or two after every push.

#### Option B — Download and open locally (works offline)

1. Open the raw file:
   https://raw.githubusercontent.com/MJha1/VendorManagement/main/vendor-onboarding-prototype.html
2. Save the page to your computer (`Ctrl+S` / `Cmd+S`), keeping the `.html` extension.
3. Double-click the saved file to open it in any browser.

No server or internet connection is needed — the fonts and scripts are inlined
into the single file.

#### Option C — Clone the repo and open the file

```bash
git clone https://github.com/MJha1/VendorManagement.git
cd VendorManagement
# then open vendor-onboarding-prototype.html in your browser
# macOS:   open vendor-onboarding-prototype.html
# Windows: start vendor-onboarding-prototype.html
# Linux:   xdg-open vendor-onboarding-prototype.html
```
